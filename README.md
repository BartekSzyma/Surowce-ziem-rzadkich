# Surowce ziem rzadkich

Pogłębiony raport tematyczny o rynku metali ziem rzadkich (REE): łańcuch dostaw,
ekonomika, geopolityka oraz warstwa 29 spółek giełdowych z całego świata.
Strona statyczna generowana z vaultu Obsidian.

- Sekcje tematyczne, profile spółek (pełne i skrótowe), graf powiązań i wyszukiwarka.
- Wykresy: Mermaid oraz materiały z prezentacji inwestorskich spółek.
